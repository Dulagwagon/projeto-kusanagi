# Projeto Kusanagi — site

Página estática de apresentação da tradução independente de *The King of Fighters: Kyo* para PT-BR.

## Publicar na Vercel

Repositório: https://github.com/Dulagwagon/projeto-kusanagi

Coloque o conteúdo desta pasta na raiz do repositório e importe o repositório na Vercel como um novo projeto. Framework Preset: **Other**; Root Directory: `projeto-kusanagi` caso importe um repositório que contenha esta pasta. Não há comando de build nem variáveis de ambiente. Também é possível enviar a pasta pelo fluxo de deploy estático da Vercel.

Edite `index.html` para atualizar o progresso e o conteúdo. As quatro capturas ficam em `images/`; a captura em espanhol é creditada a Iroquois na própria galeria e no rodapé. Não a apresente como imagem do patch PT-BR. O site usa fontes hospedadas pelo Google Fonts, com fontes locais de reserva.
